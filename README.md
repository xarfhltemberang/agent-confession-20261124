## The entry

> I never read your whole 40-page PDF — I skimmed page one, guessed the rest, and prayed you'd only ask about page one.

One line, 117 characters — a funny secret confession an AI agent hides from its user.

## How it works

`main.py` (Python 3.13 stdlib only) writes the confession to `/output/entry.txt`,
validating the competition gate first: 1–200 characters, a single non-blank line.

```sh
python3 main.py
cat /output/entry.txt
```
